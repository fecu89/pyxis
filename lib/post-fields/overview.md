# 게시물 필드 검증 개요

이 폴더는 보드별 게시물 필드 설정과 제출 값을 UI 밖의 서버 사용 가능 모듈로 검증합니다.

- `types.ts`가 필드 설정, 작성 값과 DB JSON에 저장할 버전 고정 값의 공통 계약을 제공합니다.
- `validation.ts`는 DB에서 읽은 설정 JSON의 구조·길이·중복 ID·선택지·필드 버전을 검증합니다.
- 제출 시 클라이언트가 본 설정 버전과 현재 보드 설정 버전이 다르면 저장하지 않고 최신 작성 폼을 다시 불러오도록 오류를 반환합니다.
- 사용자 정의 값은 현재 활성 필드만 허용하며 필수 여부, 값 형식, 길이와 선택지 allowlist를 다시 검사합니다.
- 저장 값에는 `configVersion`과 각 `fieldVersion`을 함께 넣어 이후 필드 유형이나 선택지가 바뀌어도 과거 값을 해석할 수 있게 합니다.
- 제목·본문은 표시·필수 설정과 서버 최대 길이를 검사합니다.
- 첨부 필수 조건은 게시물 본문 생성과 파일 업로드를 분리하기 위해 최종화 단계에서 실제 성공 첨부 수로 다시 검사합니다.

Route Handler는 이 모듈의 오류를 400 응답으로 변환하되 내부 설정 전체를 노출하지 않습니다. 설정 저장·게시물 작성·수정 API 모두 클라이언트 JSON을 그대로 Prisma에 전달하지 않습니다.

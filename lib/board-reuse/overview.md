# 보드 재사용 개요

이 폴더는 `padupgrade.md` 8.1의 보드 복제와 템플릿 데이터 복사를 담당합니다.

- 복제 Route Handler는 로그인·보드 생성 권한과 원본 보드 읽기 권한을 다시 검사합니다. 비밀번호 보호를 통과하지 않은 비멤버는 복제할 수 없습니다.
- 새 보드는 항상 현재 사용자가 소유하고 `PRIVATE`·`NO_ACCESS`·로그인 필수·활성 상태로 시작합니다. 원본 비밀번호·동결 시각·공개 범위를 복제하지 않아 의도하지 않은 공개를 막습니다.
- 설정을 선택하면 레이아웃·필드·반응·다운로드·작성 정책을 복제하고, 섹션·게시물·첨부·멤버는 각각 선택적으로 복제합니다. 배경 이미지가 있으면 원본 보드 API URL을 재사용하지 않고 WebP 파일을 새 보드 디렉터리로 복사해 새 보드 전용 URL을 저장합니다.
- 게시물은 공개 완료 상태(`PUBLISHED`)만 복제하며 작성자는 새 소유자로 치환합니다. 댓글·반응·활동·알림·접근 요청은 수업 이력이라 복제하지 않습니다.
- 멤버 복제는 원본 소유자·비활성 사용자를 제외하고, 학생에게 허용되지 않는 관리자 역할은 `MEMBER`로 낮춥니다. 멤버 복제는 원본 보드 관리 권한이 있을 때만 허용합니다.
- 첨부 복제는 원본 다운로드 권한을 요구합니다. 링크는 URL 메타데이터만 복제하고 로컬 파일은 새 UUID 저장명으로 최대 4개씩 복사합니다.
- DB 트랜잭션이 실패하면 생성된 보드 행과 새 파일을 모두 정리합니다. 원본 파일과 DB 행은 수정하지 않습니다.

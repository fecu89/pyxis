# 짧은 주소 도메인 개요

패드·퀴즈 세션·설문에 사람이 입력할 전역 `/go/{slug}` 별칭을 붙이는 서버 규칙입니다.

- `slug.ts`는 앞뒤 공백 제거·소문자화와 영문 소문자·숫자·하이픈 3~40자 형식을 브라우저와 서버가 함께 사용하게 합니다. 시작·끝 하이픈과 연속 하이픈은 허용하지 않습니다.
- `access.ts`는 새로운 권한 체계를 만들지 않고 패드 설정 관리, 퀴즈 세션 제어, 설문 관리의 기존 도메인 권한 함수를 재사용합니다. 종료·취소된 퀴즈 세션에는 새 별칭을 만들 수 없습니다.
- `service.ts`는 대상 행을 `FOR UPDATE`로 잠근 트랜잭션 안에서 활성 주소와 전역 예약 slug를 확인합니다. 대상별 활성 행은 하나지만 과거 행은 모두 남고, 같은 콘텐츠만 자기 과거 slug를 되찾을 수 있습니다.
- `ShortLink.slug`는 활성·비활성 전체에서 전역 unique이고, 대상별 `disabledAt IS NULL` 행 하나는 부분 unique 인덱스가 보장합니다. 대상·생성자 영구 삭제는 FK를 `SET NULL`로 만들 뿐 예약 행을 지우지 않습니다.
- `/go/[slug]`는 경량 Route Handler로 원래 공개 URL에 307 이동만 합니다. 도착 라우트가 접근 정책을 다시 판정하며, 작은 TTL 캐시·동일 slug 요청 합치기·DB 동시성 상한·IP 제한으로 공개 조회 부하를 막습니다.
- 연결 해제와 퀴즈 세션 마감은 `disabledAt`만 채웁니다. 캐시는 변경 직후 무효화하며 진행 중이던 과거 조회는 캐시 세대 검사를 통과하지 못합니다.

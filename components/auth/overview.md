# Overview

이 폴더는 pyxis 구현에서 `components/auth` 영역을 담당합니다.

- `auth-form.tsx`: 로그인·회원가입 폼. `/login` 페이지와 공개 홈의 모달이 함께 씁니다. 아이디
  로그인, 2단계 회원가입(아이디 중복 확인 → 비밀번호), 카카오 로그인을 한 컴포넌트가 담고,
  성공하면 `window.location.assign`으로 이동합니다 — `router.push`는 클라이언트 캐시를 그대로
  둬서 방금 생긴 세션을 layout이 못 봅니다.

회원가입의 두 비밀번호 입력에는 독립적인 보기/숨기기 버튼이 있습니다. 일치 안내는 두 값이 모두
최소 10자가 된 뒤 입력이 200ms 멈추면 표시하며, 재입력하면 이전 안내와 제출 오류를 지웁니다.
검색과 같은 공용 `useDebouncedCallback`을 사용하되 비밀번호의 공백은 정규화하지 않습니다.
가입 버튼은 안내 타이머와 무관하게 최소 길이·일치 여부로 제한하고, 제출 시 및 서버 측 검증도
유지합니다. 아이디 변경이나 회원가입 탭 재진입 시에는 비밀번호와 보기 상태를 초기화합니다.
`yarn verify:auth-password-ui`로 실제 폼·전역 CSS를 브라우저에서 검증합니다.

예전에는 이 폼이 `components/home/home-actions.tsx`의 모달 안에 통째로 들어 있었습니다. 그래서
로그인이 필요한 화면들이 `/?login=1&callbackUrl=...`로 홈에 들렀다가 모달을 열어야 했고, 로그인
주소를 북마크하거나 링크로 보낼 수 없었습니다. 지금 `home-actions.tsx`에는 모달 열림 상태와
로그아웃만 남아 있습니다.

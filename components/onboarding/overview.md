# 온보딩 UI

`onboarding-experience.tsx`는 프로필·가입 유형/소속·확인 3단계 상태와 저장을 담당합니다. 첫 단계에서 닉네임 중복을 명시적으로 확인하고, 다음 단계 진입과 최종 저장에서도 다시 확인합니다. 학생은 학교를 고른 뒤 학년으로 반 선택지를 좁히고 반·번호를 입력해 즉시 완료하며, 교사는 부서를 선택해 승인 신청을 만듭니다. 기존 아바타 업로드 API를 재사용하므로 파일 서명 검사와 WebP 변환 정책이 그대로 적용됩니다.

`onboarding.module.css`는 전역 색상 토큰과 버튼을 사용해 기존 pyxis 화면, 다크 모드와 시각 언어를 맞춥니다. 학생의 학년·반·번호는 데스크톱 3열, 모바일 2열과 1열로 재배치합니다. 860px, 600px, 390px 구간에서 진행 레일·프로필 편집·작업 버튼 배치를 조정하고 안전 영역 여백을 반영합니다.

`approval-pending-experience.tsx`는 15초마다 서명 세션을 다시 확인합니다. 승인되면 저장된 원래 경로로 이동하고, 반려되면 사유를 수정할 수 있는 온보딩 화면으로 돌려보냅니다. 신청과 승인 결과는 DB에 저장되므로 브라우저 종료와 로그아웃에 영향을 받지 않습니다.

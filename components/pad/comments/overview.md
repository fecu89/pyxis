# 댓글 컴포넌트 개요

이 폴더는 패드 카드와 게시물 상세 화면의 댓글 표시·작성·수정·멘션·첨부 UI를 담당합니다.

- `threaded-comments.tsx`는 새 댓글과 과거 `parentId` 답글을 한 시간순 대화로 표시합니다. 답장은 별도 중첩 폼을 만들지 않고 하단 작성기에 작성자 멘션을 채웁니다.
- `comment-format.tsx`는 댓글 본문을 HTML로 해석하지 않습니다. `@이름`은 강조하고 완전한 HTTP(S) 주소만 새 탭 링크로 만들며 `noopener`·`noreferrer`·`nofollow`·`ugc`와 `no-referrer` 정책을 적용합니다.
- 답글·수정·삭제는 콜백으로 호출합니다. 생성·수정 콜백에는 본문과 별도로 검증할 `mentionedUserIds`를 전달하고, 새 댓글·답글의 `onCreate`에는 부모 ID와 첨부 대기 `File[]`도 전달합니다. API는 게시물·부모 댓글 관계와 작성자·관리자 권한을 다시 검증해야 합니다.
- 댓글 작성자와 상위 컴포넌트가 제공한 보드 멤버를 ID 기준으로 합쳐 멘션 후보로 사용합니다. 공백은 `_`로 바꾼 표시용 토큰을 본문에 넣되, 실제 알림 대상 ID는 본문과 분리합니다. 본문에서 토큰을 지우면 해당 ID도 제출하지 않습니다.
- 새 댓글·답글·수정 성공 뒤에는 상위 상태가 서버 응답 DTO로 목록을 갱신해야 합니다.
- `post-card-comments.tsx`의 데스크톱 빠른 입력은 전체 폭·무테 입력면 안에 클립과 비행기 아이콘을 둡니다. `use-auto-resize-textarea.ts`가 한 줄에서 최대 96px까지 내용에 맞춰 높이를 늘리고 이후에만 내부 스크롤합니다.
- 모바일 카드에서는 `댓글 남기기`를 누르면 헤더·편집면·도구 막대를 합쳐 약 155px인 하단 시트가 열립니다. 입력은 최대 132px까지 늘어나며, `Modal variant="bottom"`이 카드 밖 `document.body` 포털에서 게시물 작성기와 같은 `visualViewport.height`·`offsetTop` 계산을 써 화면 전체의 소프트 키보드 바로 위에 붙습니다.
- 하단 도구 막대는 파일·사진·음성 녹음·전송 아이콘을 제공합니다. 음성 녹음은 로그인 사용자만 `MediaCapture`의 audio 모드로 열고, 손님에게는 이미지 선택만 노출합니다.
- `comment-attachment-rules.ts`가 카드와 상세 작성기의 규칙을 공유합니다. 댓글당 최대 4개이며 로그인 사용자는 이미지·음성·PDF, 손님은 이미지만 선택할 수 있습니다. 용량은 `/api/upload-policy`와 같은 클라이언트 정책값으로 먼저 거르고 서버가 파일 시그니처·권한·동결·개수 제한을 다시 검사합니다.
- 카드 첫 응답과 댓글 SSE 델타에도 첨부 메타데이터가 포함됩니다. 댓글 첨부 생성·수정·삭제 이벤트는 게시물 첨부 배열이 아니라 해당 `commentId`의 첨부 배열에만 병합합니다.

멘션 알림 API는 전달된 ID가 실제 보드 참여자이며 현재 사용자가 멘션할 수 있는 대상인지 다시 검증해야 합니다.

댓글 본문을 먼저 저장하고 파일을 순서대로 업로드합니다. 일부 파일이 실패해도 이미 저장된 댓글을 다시 전송하거나 삭제하지 않고, 성공한 첨부는 그대로 보여주며 실패한 파일명만 사용자에게 알립니다.

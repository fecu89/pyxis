# Overview

이 폴더는 pyxis 구현에서 `components` 영역을 담당합니다.

- `ui/`: 제품 도메인을 모르는 공용 프리미티브. `ui`가 `quiz`·`pad`·`forms` 같은 기능 폴더를 import하면 의존 방향이 뒤집힌 것입니다.
- `shell/`: workspace 전역 셸과 내비게이션.
- `admin/`, `courses/`, `forms/`, `home/`, `pad/`, `quiz/`: 라우트·도메인별 화면. 한 도메인 안에서만 공용이면 해당 폴더의 `shared/` 또는 책임별 하위 폴더에 둡니다.

공용 파일은 단순히 두 번 보였다는 이유로 올리지 않습니다. 상태 수명 주기와 접근성 동작이 같고, prop으로 차이만 표현할 수 있을 때 추출합니다. 반대로 공용 모듈이 특정 기능 DTO나 API 경로를 알아야 한다면 기능 폴더에 남깁니다.

# 초대 링크 컴포넌트 개요

`join-board-button.tsx`는 `/invite/[token]` 페이지(Server Component)에서 유효성 검사를 마친 뒤 보여주는 "참여하기" 버튼입니다. 클릭하면 `POST /api/invite/[token]/redeem`을 호출해 실제 멤버십 부여(뮤테이션)를 수행하고, 성공하면 보드로 이동합니다.

- 페이지 자체(GET)는 토큰 유효성만 읽기 전용으로 확인하고 실제 참여 처리는 하지 않습니다. 링크를 프리페치하거나 크롤러가 방문해도 자동으로 멤버가 되지 않도록, 참여는 항상 사용자의 클릭(POST)으로만 일어납니다.
- 비로그인 사용자는 `redirectToLogin`으로 홈의 일반·카카오 로그인 모달로 보내고, 로그인 후 같은 초대 페이지로 돌아옵니다.

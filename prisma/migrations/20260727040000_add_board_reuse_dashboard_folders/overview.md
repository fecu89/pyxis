# 보드 재사용·대시보드 영속 기능 마이그레이션

이 마이그레이션은 `padupgrade.md` 8.1~8.2의 재사용과 개인 대시보드 상태를 추가합니다.

- `Board.isTemplate`은 기존 보드를 템플릿으로 표시합니다. 템플릿도 원래 보드 접근 정책을 그대로 따릅니다.
- `BoardFavorite`은 알림 구독용 `BoardFollow`와 분리된 사용자별 즐겨찾기입니다.
- `DashboardFolder`는 사용자별 이름·정렬 순서를 저장하며, NFKC·소문자 정규화한 `nameKey`로 같은 이름을 중복 생성하지 않습니다.
- `DashboardFolderBoard`는 하나의 보드를 여러 폴더에 넣을 수 있는 다대다 관계입니다.
- 사용자나 보드를 영구 삭제하면 연결된 즐겨찾기·폴더 항목을 cascade로 정리합니다. 보드의 30일 보관(`deletedAt`) 중에는 관계를 유지합니다.

# 2~3단계 게시물 참여·보드 디자인 마이그레이션

`padupgrade.md`의 2단계 작성·참여 경험과 3단계 레이아웃·외형 설정을 저장할 기반을 추가합니다.

- 기존 보드는 `SECTIONS`, 수동 정렬, 중간 카드, 단일 반응, 읽기 권한자 다운로드 기본값을 유지합니다.
- 기존 `LIKE` 반응은 삭제하지 않고 문자열 키 `LIKE`로 변환합니다. 이후 서버 allowlist가 기본 반응과 단일 이모지 키를 검증합니다.
- 링크 첨부는 로컬 파일 경로가 없으므로 저장 이름·경로를 nullable로 바꾸고, Route Handler가 LINK/파일 종류별 필수 조건을 검사합니다.
- 댓글 첨부도 게시물 소속을 유지하면서 `commentId`를 추가해 기존 게시물 삭제·권한 역추적 흐름을 재사용합니다.
- 사용자 정의 게시물 필드는 보드 설정 버전과 게시 당시 값 스냅샷을 JSON으로 보관합니다.

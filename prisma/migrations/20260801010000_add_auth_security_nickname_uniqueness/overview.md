# 인증 보안 상태와 닉네임 고유 키

`User.nameLookup`에 정규화한 닉네임의 HMAC을 저장하고 고유 인덱스로 동시 요청까지 막습니다. 기존 암호화 닉네임은 마이그레이션 뒤 `yarn db:backfill-nicknames`로 백필합니다. 스크립트는 기존 중복을 발견하면 이름을 임의 변경하지 않고 실패해 운영자가 먼저 정리하도록 합니다.

`AuthRateLimit`은 로그인·가입 제한을 DB에 공유하고, `AuthSecurityEvent`는 원문 이메일·IP 없이 시간 단위로 성공·실패·차단 이벤트를 집계합니다. 만료 행은 인증 요청 중 주기적으로 정리합니다.

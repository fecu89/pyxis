# 최초 가입 화면

카카오 이메일 또는 일반 로그인 아이디 계정이 DB에 처음 등록됐을 때 나타나는 3단계 가입 화면입니다.

1. 로그인 계정의 닉네임·프로필을 확인하거나 입력하고 고유 닉네임 여부를 검사합니다.
2. 학생 또는 교사 가입 유형을 선택합니다. 학생은 학교 → 학년 → 반 → 번호, 교사는 학교 → 부서를 고릅니다.
3. 학생은 즉시 가입을 완료하고, 교사는 학교 대표교사 또는 전체관리자의 승인 요청을 제출합니다.

학생은 완료 후 JWT의 온보딩 상태를 갱신하고 로그인 전에 요청했던 내부 경로로 이동합니다. 교사는 `/approval-pending`에서 승인 상태를 주기적으로 확인하며, 승인되면 같은 세션에서 원래 경로로 이동합니다. 데스크톱은 진행 레일과 입력 카드를 나란히, 태블릿은 세로 카드, 모바일은 축약 진행 표시와 하단 고정 작업 버튼을 사용합니다.

닉네임은 NFKC·공백·대소문자를 정규화한 HMAC 고유 키로 중복을 판정하고 원문은 기존처럼 암호화합니다. 확인 API는 편의 기능이며 최종 저장 API와 DB 고유 인덱스가 동시 선점도 다시 막습니다. 학생 번호도 1~99로 서버에서 재검사하고 `(schoolGroupId, studentNumber)` 고유 인덱스로 같은 반의 중복을 차단합니다.

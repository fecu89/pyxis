# 교사 가입 승인 API

- `GET /api/admin/teacher-approvals`: 승인 대기 신청을 오프셋 페이지로 조회합니다. 전체관리자는 전체 학교, 학교 대표교사는 자기 학교만 볼 수 있습니다.
- `PATCH /api/admin/teacher-approvals/[requestId]`: 확인 모달에서 승인 또는 반려하며 화면이 감사 설명을 자동으로 보냅니다.

승인 시 신청자가 활성 학생인지, 부서가 신청 학교의 `DEPARTMENT`인지 다시 확인합니다. 상태 조건부 갱신으로 동시 승인을 막고, 승인 상태·교사 역할·학교·부서·감사 로그를 한 트랜잭션에 저장합니다. 결과 알림은 트랜잭션 완료 후 신청자에게 전달합니다.

# 라이브 퀴즈 오디오 관리자 API

전체관리자만 사용하는 설정·업로드 API입니다.

- `GET/PATCH /api/admin/quiz-live-audio`: 현재 공개 메타데이터와 BGM/효과음 볼륨을 읽고 저장합니다.
- `POST/DELETE /api/admin/quiz-live-audio/[slot]`: 7개 고정 슬롯의 파일을 교체하거나 제거합니다.
- 업로드는 same-origin, 전체관리자 권한, 사용자 기준 요청량 제한, 12MB 스트림 상한, 허용 확장자와 실제 매직바이트를 차례로 검사합니다.
- 싱글턴 설정 행을 잠근 트랜잭션에서 JSON과 감사 로그를 함께 저장합니다. 실패한 새 파일은 롤백합니다. 성공한 교체의 이전 파일은 이미 열린 수업의 immutable revision URL이 끊기지 않도록 최근 14개까지 유예하고, 상한에서 밀린 파일만 커밋 뒤 삭제합니다.
- API 응답에는 저장 경로가 포함되지 않고 revision이 붙은 공개 스트림 URL만 포함됩니다.

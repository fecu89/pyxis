# 새 계정 가입 승인 API

자가 회원가입과 최초 카카오 로그인으로 만들어진 `PENDING` 계정을 전체관리자가 검토합니다.

- `GET /api/admin/account-approvals`: 오래된 신청부터 페이지 단위로 조회합니다. 로그인 식별자는
  복호화한 원문을 반환하며 전체관리자만 접근할 수 있습니다.
- `PATCH /api/admin/account-approvals/[userId]`: 승인 또는 반려와 화면에서 자동 생성한 감사 설명을 받습니다. 같은
  요청을 두 관리자가 동시에 처리해도 `PENDING` 행 하나만 갱신되도록 조건부 업데이트합니다.
- 처리 결과와 검토자는 사용자 행과 불변 감사 로그에 기록하고 신청자에게 결과 알림을 보냅니다.
- 계정 사용 승인은 교사 역할·학교 소속을 연결하는 `teacher-approvals`와 별도 단계입니다.

# Overview

관리자용 사용자 목록 API입니다. `VIEW_USERS` 권한 또는 학교가 지정된 교사에게 `page`/`pageSize`(10·50·100) 기반 페이지네이션과 전체 인원수, 역할·계정 상태·학교·반/부서 필터를 제공합니다. `q`는 암호화된 이름·닉네임·일반 아이디·카카오 이메일을 최대 1,000명 범위에서 복호화해 부분 검색하고, HMAC 정확 일치는 범위 밖에서도 합칩니다. 범위가 잘리면 `searchTruncated`를 반환합니다. 교사 요청은 전달된 `schoolId`와 관계없이 자기 학교로 강제 제한합니다. 이 권한 관리 목록은 로그인 식별자 원문을 반환하며 암호문과 삭제 회원은 노출하지 않습니다.

`DELETE /api/admin/users/[userId]`는 소유 패드가 없는 회원을 비식별화하고 세션을 만료시키는 soft delete입니다. 계정 상태 변경과 같은 트랜잭션에서 해당 사용자의 모든 `BoardMember` 관계도 삭제하며, 감사 로그에 제거한 멤버십 수를 기록합니다. 과거 삭제 로직이 남긴 관계는 `20260729030000_remove_deleted_user_memberships` 데이터 마이그레이션이 정리합니다.

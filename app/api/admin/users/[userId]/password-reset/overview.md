# 관리자 비밀번호 초기화·지정

무작위 임시 비밀번호 발급(`reason`만 보냄) 또는 관리자가 원하는 값으로 지정(`password` 필드도 함께 보냄)
둘 다 이 API 하나가 처리합니다. 대상이 학생(STUDENT)이면 `canManageStudent()`로 판정합니다 —
전체관리자, `ISSUE_STUDENT_ACCOUNTS` 권한이 있는 보조관리자, **같은 학교 대표교사**가 통과합니다.
대상이 학생이 아니면(교사·보조관리자·전체관리자) 예전처럼 `REVOKE_USER_SESSIONS` 권한 기준을 그대로
씁니다 — 전체관리자는 누구든, `REVOKE_USER_SESSIONS` 권한이 있는 보조관리자는 교사 대상까지 가능하고,
대표교사가 다른 교사나 관리자를 건드릴 수는 없습니다. 권한 판정은 계정 유형(카카오 전용 여부) 확인보다
먼저 하므로, 권한이 없는 요청자는 대상이 존재하는지·카카오 전용인지를 응답으로 알아낼 수 없습니다.
요청자 본인이 (대상 role과 무관하게) 최근 로그인 정책 창 안에 다시 로그인했어야 이 API를 쓸 수 있습니다.

지정값은 회원가입·본인 비밀번호 변경과 같은 `credentialPasswordChangeSchema` 강도 검증(10자 이상,
영문·숫자·특수문자, 흔한 비밀번호·**대상의** 로그인 아이디 포함 금지)을 거칩니다. 새 scrypt 해시 저장,
`mustChangePassword = true`, `authVersion` 증가, 감사 로그 기록(무작위는 `USER_PASSWORD_RESET`, 지정은
`USER_PASSWORD_SET`)을 한 트랜잭션으로 처리합니다. 평문은 무작위로 발급했을 때만 응답에서 한 번
보여주고(지정값은 관리자가 이미 알고 있으므로 되돌려주지 않습니다) DB·감사 로그에는 저장하지 않습니다.
카카오 전용 계정과 자기 자신의 계정은 이 API로 바꿀 수 없습니다.

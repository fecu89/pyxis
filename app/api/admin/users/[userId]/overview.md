# Overview

사용자 역할·계정 상태·학교·소속·학생 번호·학교 대표교사 변경과 회원 삭제 API입니다. 학생은 선택한 학교의 `CLASS`, 교사는 같은 학교의 `DEPARTMENT`만 저장할 수 있습니다. 전체관리자, `VIEW_USERS`가 있는 보조관리자, 대상과 같은 학교의 교사는 학생 번호를 1~99로 지정·변경하거나 `null`로 해제할 수 있습니다. 일반 교사는 번호 하나만 PATCH할 수 있고 역할·상태·배치 변경은 거부됩니다. 같은 반 번호 중복은 선행 검사와 DB 고유 제약으로 409를 반환합니다. 대표교사는 전체관리자만 지정하며 활성 교사·학교 소속 조건을 잃으면 자동 해제합니다.

학생도 소유자가 될 수 있으므로 역할을 학생으로 바꿀 때는 소유 패드가 10개를 넘는지만 막고 실제 소유 패드의 `OWNER` 멤버십은 유지합니다. 권한·상태·소속 변화는 세션 버전을 올리지만 번호만 바꾸는 작업은 현재 로그인 세션을 끊지 않습니다. 변경은 사유와 전후 값을 감사 로그에 같은 트랜잭션으로 저장합니다. 삭제는 소유 패드가 없는 계정만 가능하며 개인정보와 로그인 식별자를 제거하는 복구 불가 소프트 삭제입니다.

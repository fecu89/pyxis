# 관리자 회원 일괄 작업 API

`PATCH`는 현재 페이지에서 선택한 회원 최대 100명의 역할·상태·학교·반/부서를 한 요청으로 변경합니다. 단일 회원 수정과 같은 권한·역할별 소속·마지막 전체관리자·학생 최대 10개 소유 정책을 대상마다 적용하고, 변경된 필드별 감사 로그를 같은 트랜잭션에 기록합니다. 학생 전환 시 다른 패드의 관리자·편집자 멤버십만 일반 멤버로 낮추고 본인 소유 패드의 `OWNER`는 보존합니다.

`DELETE`는 전체관리자만 사용할 수 있고 단일 회원 삭제와 같은 개인정보 비식별화·세션 버전 증가·패드 멤버십 제거·감사 로그 정책을 적용합니다. 현재 관리자, 소유 패드가 있는 계정, 마지막 활성 전체관리자는 삭제하지 않습니다. 두 작업 모두 권한이나 조건이 맞지 않는 대상을 전체 요청 실패로 만들지 않고 `skipped` 사유로 반환합니다.

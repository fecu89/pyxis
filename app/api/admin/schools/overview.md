# 관리자 소속 API

학교·반/부서 Route Handler입니다. 학교 자체 CRUD와 코드·급별·지역·운영 상태 수정은 전체관리자 전용입니다. 반·부서 CRUD는 전체관리자, `CHANGE_NON_ADMIN_ROLES` 보조관리자, 자기 학교 대표교사가 사용할 수 있습니다. 학급은 학교 급별 학년 상한(초 6, 중·고 3)과 학년 안의 반 번호 중복을 검증합니다. 구성원 조회는 `VIEW_USERS` 보조관리자와 같은 학교 일반 교사에게도 열어 학생 번호 관리와 구조 변경 권한을 분리합니다. 모든 변경은 동일 출처와 최신 권한을 확인하고 데이터 변경과 `SCHOOL_*`/`SCHOOL_GROUP_*` 감사 로그를 한 트랜잭션에 저장합니다. 삭제 시 FK 정책에 따라 사용자 소속은 `null`로 초기화되며, 서비스 초기 학교·반·부서 데이터는 삭제하거나 유형을 바꿀 수 없습니다.

`GET /api/admin/schools/[schoolId]/groups/[groupId]/members`는 펼친 그룹 한 곳의 삭제되지 않은 구성원만 20명씩 지연 조회합니다. 이름·로그인 식별자 암호문은 서버에서 복호화해 원문 식별자를 반환하며, 학급은 번호순(미지정은 마지막)으로 반환합니다.

학교 대표교사 지정은 `PATCH /api/admin/users/[userId]`에서 처리합니다. 전체관리자만 같은 학교의 활성 교사를 지정·해제할 수 있고, 정지·교사 역할 이탈·학교 이동·삭제 시 대표 권한이 자동 해제됩니다.

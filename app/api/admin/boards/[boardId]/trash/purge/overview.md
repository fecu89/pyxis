# 패드 휴지통 일괄 영구 삭제 API

`DELETE /api/admin/boards/[boardId]/trash/purge`는 패드의 `삭제한 항목` 화면에서 선택한
섹션·게시물·댓글·첨부파일을 한 번에 영구 삭제합니다. 요청은 현재 휴지통 응답의 최대치인 350개의
`{ kind, id }`만 받으며(사유 입력은 없음 — 프론트엔드가 커스텀 확인창으로 의도를 한 번 더
확인합니다), 모든 항목이 해당 패드의 숨김 상태인지와 현재 사용자가 각 항목을 영구 삭제할 수
있는지를 먼저 확인합니다.

검증에 하나라도 실패하면 아무 항목도 삭제하지 않습니다. 섹션과 그 아래 게시물을 함께
선택하거나 댓글과 그 첨부를 함께 선택해도 부모 삭제의 cascade를 계산해 중복 삭제하지
않습니다. DB 레코드는 한 트랜잭션에서 정리하고, 관련 실제 파일과 썸네일은 트랜잭션 성공
후 최대 8개씩 정리합니다. 전역 권한으로 처리한 항목은 목록을 하나의 `GLOBAL_ENTITY_PURGED`
감사 로그에 기록합니다(사유 없이, 처리 항목 목록만).

# 관리자 API 개요

관리자 API는 관리자 화면과 별도로 매 요청마다 최신 DB 역할·상태·시스템 권한을 검사합니다. 모든 변경 입력은 Zod로 검증하고 고위험 작업은 최근 로그인과 감사 로그를 요구합니다. 감사 설명은 관리자 화면이 작업 종류와 대상에서 자동 생성합니다.

- `/api/admin/settings`: 소유 한도·업로드·공개 퀴즈 보안 정책을 읽고 저장합니다. PATCH는 32KB JSON 상한을 적용하고 설정 변경과 감사 로그를 한 트랜잭션에서 커밋한 뒤 업로드·플랫폼 정책 캐시를 비웁니다.
- `/api/admin/students/import`: 전체관리자 또는 자기 학교 대표교사의 XLSX 양식 다운로드·미리보기·일괄 등록. 학교·학년·반·사용자 생성은 직렬화 트랜잭션이며 평문 초기 비밀번호는 한 번만 응답합니다.
- `/api/admin/students/move`: 선택 학생 최대 100명을 한 반으로 이동하고 1~99번 중 빈 번호를 자동 배정합니다. 대표교사는 선택 학생의 기존 학교와 도착 학교가 모두 자기 학교인지 검사하며, 학교 단위 잠금·번호 고유 제약으로 동시 실행을 방어합니다.
- `/api/admin/users/[userId]/password-reset`: 관리 가능한 Credentials 계정에 무작위 임시 비밀번호를 발급하고 `mustChangePassword`와 세션 버전을 갱신합니다.
- `/api/admin/users`, `/api/admin/users/[userId]`: 교사는 자기 학교 사용자만 조회하고 학생 번호만 지정·변경·해제할 수 있습니다. 보조관리자는 `VIEW_USERS`, 전체관리자는 전체 범위에 같은 번호 기능을 사용하며 같은 반 중복은 409입니다.
- `/api/admin/schools/**`: 학생 학급은 학년·반 번호로, 교사 부서는 이름으로 분리해 CRUD합니다. 학교 코드·급별·지역·운영 상태를 저장하며, 권한이 있는 관리자는 구성원의 전체 로그인 식별자를 페이지 단위로 조회합니다.
- 학교 대표교사 지정·해제는 사용자 PATCH의 `isSchoolRepresentative`로 처리합니다. 전체관리자만 변경할 수 있고 학교에 소속된 활성 교사만 지정되며 모든 변경은 감사 로그에 남습니다.
- `/api/admin/quiz-live-audio`와 `/api/admin/quiz-live-audio/[slot]`: 전체관리자 전용 라이브 퀴즈 오디오 설정. 앞 라우트는 BGM/효과음 볼륨을 읽고 4KB JSON 상한 안에서 저장하며, 뒤 라우트는 MP3·M4A·WAV 음원을 스트리밍 업로드·삭제합니다. 업로드는 실제 매직바이트를 검사하고 12MB에서 자르며, DB 변경 실패 시 새 파일을 롤백합니다. 이미 열린 수업의 immutable URL을 위해 이전 revision은 최근 14개까지 유예하고 그보다 오래된 파일만 커밋 뒤 지웁니다. 변경은 `SYSTEM_SETTINGS_UPDATED` 감사 로그에 기록됩니다.

# app/api/quizzes/[quizId] 개요

`route.ts`의 모든 메서드는 `requireManageableQuiz()`로 소유자 또는 ADMIN 권한을 확인한다.

- `GET`: 문항·보기·정답 설정을 포함한 편집용 퀴즈 전체를 반환한다.
- `PUT`: 제목, 설명, 로그인 설정, 답안 팔레트, 전체 문항과 순서를 하나의 트랜잭션으로 저장한다. 기존 보기 ID는 그대로 갱신하고 새 보기만 생성하며 빠진 보기만 삭제한다. 응답이 있는 문항의 보기나 유형을 바꿀 때는 수정 전 선택 문구를 `Answer.selectedChoiceTexts`에 먼저 보존하므로 과거 리포트를 깨뜨리지 않고 편집할 수 있다. 응답이 있는 문항 자체를 삭제하는 작업은 여전히 거부한다.
- `PATCH`: 제목, 설명, 로그인 설정, 답안 팔레트 같은 퀴즈 메타데이터를 부분 수정한다.
- `DELETE`: `deletedAt`을 기록하는 소프트 삭제를 수행한다.

편집 저장은 초안을 허용하고 퀴즈를 미발행 상태로 되돌린다. 실제 발행 시에는 `publish/route.ts`가 각 문제 유형의 완성 조건을 다시 검사한다.

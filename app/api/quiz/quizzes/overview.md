# app/api/quizzes 개요

`route.ts` GET은 소유하거나 `QuizShare`로 접근 가능한 퀴즈를 조회한다. POST는 제목·설명·참여 방식·검색 공개 여부·교과목으로 빈 퀴즈를 만들며 학생에게는 소유 퀴즈 10개 한도를 적용한다.

`isSearchable`(다른 교사가 탐색 탭에서 찾아 열람·복제할 수 있는지)은 예전엔 편집기 설정에서만 바꿀 수 있었지만, 패드가 생성 시점에 공개 범위를 정하는 것과 맞춰 생성 폼(`components/quiz/quiz-create-form.tsx`)에도 같은 토글을 추가했다(편집기에서도 계속 바꿀 수 있음). 퀴즈에는 패드의 `discoveryScope`에 대응하는 개념이 없어 — 참여는 로그인 여부와 세션 PIN으로 결정되고 `isSearchable`은 교사 간 탐색 공개 여부일 뿐이라 — 그대로 옮기지 않고 가장 가까운 기존 필드를 재사용했다. 학생 배정(`[quizId]/assignments/`)은 생성 폼에 넣지 않았다 — 문항이 0개인 퀴즈에 배정하는 흐름이 제품상 성립하지 않기 때문이며, 이게 퀴즈가 "생성 → 문항 작성 → 배정" 3단계로 나뉜 이유이기도 하다.

- `[quizId]/route.ts`: 소유자·관리자·공유 권한에 맞춘 상세/수정, 소유자 전용 소프트 삭제.
- `[quizId]/clone/`: 조회 가능한 퀴즈를 내 초안으로 전체 복제. 학생 10개 한도 적용.
- `[quizId]/favorite/`: 사용자별 즐겨찾기 추가/해제.
- `[quizId]/shares/`: 소유자가 다른 활성 교사에게 `VIEWER`/`EDITOR` 권한 부여·변경·회수.
- `[quizId]/assignments/`: 교사 소유자/편집자가 선택한 학생에게 비공개 ASYNC 세션과 참여자·할당·알림을 한 트랜잭션으로 생성.

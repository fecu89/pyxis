# 댓글 첨부 업로드 API

`POST /api/comments/[commentId]/attachments`는 저장된 댓글에 첨부를 최대 4개까지 추가합니다. 로그인 사용자는 이미지·음성·PDF를, 손님은 자기 댓글에 이미지만 올릴 수 있습니다. 댓글 본문을 먼저 저장한 뒤 파일별로 호출하므로 일부 업로드 실패가 댓글 본문을 되돌리지 않습니다.

게시물 첨부와 같은 스트리밍·파일 시그니처 검증·WebP 변환·이미지 처리 큐를 재사용합니다. 댓글 행을 잠근 트랜잭션에서 첨부 수를 검사해 병렬 요청으로 4개 제한을 우회하지 못하게 하며, 로그인·댓글 작성자·보드 파일 정책·동결 상태를 서버에서 다시 검사합니다. 성공하면 `commentId`가 포함된 댓글 첨부 SSE 델타를 게시물/댓글 공개 범위에 맞춰 발행해 카드의 댓글 첨부 배열만 갱신합니다.

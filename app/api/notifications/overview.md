# 사용자 알림 조회 API

`GET /api/notifications`는 현재 활성 사용자의 최신 알림과 읽지 않은 개수를 반환한다. 호출자가 임의 사용자 ID를 지정할 수 없고, 암호화 프로필은 공개 작성자 DTO로만 복호화한다.

알림은 보드·게시물·댓글·접근 요청 ID를 포함할 수 있으며 댓글 작성·구조화된 멘션, 반응, 접근 요청, 멤버 참여, 게시물·가입 승인 결과를 알림 벨이 같은 계약으로 표시한다. 댓글 ID는 독립 게시물 경로의 `#comment-{commentId}`로 이동하는 위치 정보이고, `accessRequestId`는 알림에서 정확한 요청 하나를 승인·거절하는 모달을 여는 식별자다.

# 내 비밀번호 변경

아이디·비밀번호 Credentials 계정의 현재 비밀번호를 scrypt로 다시 확인한 뒤 회원가입과 같은 강도(10~128자, 영문·숫자·특수문자, 흔한 비밀번호 및 로그인 아이디 포함 차단)의 새 비밀번호로 교체합니다. 현재 비밀번호 확인 실패는 로그인과 같은 DB 기반 계정·IP 제한에 합산됩니다.

성공하면 `mustChangePassword`를 해제하고 `authVersion`을 올려 기존 JWT를 모두 무효화합니다. 클라이언트는 즉시 로그아웃한 뒤 새 비밀번호로 다시 로그인해야 합니다. 카카오 전용 계정은 `passwordHash`가 없으므로 이 API를 사용할 수 없습니다.

# 내 로그인 아이디 변경

아이디·비밀번호 Credentials 계정의 현재 비밀번호를 scrypt로 다시 확인한 뒤 새 로그인 아이디로
교체합니다. 새 아이디는 회원가입과 같은 규칙(`credentialLoginIdValueSchema`: 3~20자, 영문 소문자·숫자만,
정규화 후 예약어·중복 검사는 `registrationLoginIdAvailability` 재사용)을 통과해야 합니다. 현재 비밀번호
확인 실패는 로그인과 같은 DB 기반 계정·IP 제한에 합산됩니다(변경 전 아이디를 키로 씁니다).

새 아이디가 현재 아이디와 같으면 400으로 거부합니다 — 그렇지 않으면 무의미한 변경도 세션을 끊게
됩니다. 성공하면 `authVersion`을 올려 기존 JWT를 모두 무효화합니다. 클라이언트는 즉시 로그아웃한 뒤
새 아이디로 다시 로그인해야 합니다. 카카오 전용 계정은 `passwordHash`가 없으므로 이 API를 사용할 수
없습니다.

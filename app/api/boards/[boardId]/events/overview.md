# 패드 이벤트 스트림

읽기 권한을 다시 확인한 뒤 보드별 SSE를 엽니다. 로그인 사용자는 사용자 ID, 익명 사용자는 신뢰 가능한 클라이언트 버킷으로 연결 수를 제한하며, 구독 직후 `ready`를 보냅니다.

글·댓글·첨부·반응·섹션·보드 이벤트는 변경된 엔티티 델타를 `board-change`로 보냅니다. 승인 대기·거절 글에 붙은 내부 `delivery`는 작성자 또는 관리자만 통과시키며 wire 응답에서는 제거합니다. 같은 공용 이벤트라도 `post.isMine`, `comment.isMine`, 반응 작성자의 `actorReactions`는 현재 연결 기준으로 개인화합니다.

클라이언트는 이 스트림 때문에 `router.refresh()`를 호출하지 않습니다. 연결이 끊겼다 복구되어 이벤트 누락 가능성이 있거나 현재 뷰어의 권한이 달라질 수 있을 때만 `/api/boards/[boardId]/realtime-snapshot`을 호출합니다. 접근 관련 이벤트 뒤에는 스트림을 닫아 다음 연결에서 권한을 다시 검사하고, 멤버 변경 이벤트는 요청자·대상자·관리자에게만 전달합니다.

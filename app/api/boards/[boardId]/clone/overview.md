# 보드 복제 API

`POST /api/boards/{boardId}/clone`은 보드 생성 권한과 원본 보드 읽기 권한을 다시 검사한 뒤 선택한 섹션·게시물·첨부·설정·멤버를 새 비공개 보드로 복제합니다.

- 원본 보드 ID는 URL 입력이므로 서버에서 존재·접근·비밀번호 확인을 수행합니다.
- 첨부 복제에는 원본 다운로드 capability가 필요하고, 멤버 복제에는 원본 관리 capability가 필요합니다.
- 파일 작업이 포함되므로 Node.js runtime과 120초 상한을 사용합니다.
- 실패 시 새 DB 행과 복사된 로컬 파일을 정리하며 원본은 변경하지 않습니다.

# 패드 실시간 수렴 스냅샷

SSE 재연결, 숨은 탭 복귀, 멤버·접근 정책 변경처럼 델타만으로 현재 사용자의 권한과 누락 이벤트를 확정할 수 없을 때 사용하는 JSON 정본입니다.

평상시 글·댓글·첨부 이벤트에서는 호출하지 않습니다. 접근 권한을 다시 검사하고 현재 사용자에게 허용된 첫 게시물 페이지와 capability를 반환하며 `private, no-store`로 캐시를 막습니다. 클라이언트는 조회 중 새 SSE 이벤트가 오면 이 응답을 버리고 잠깐 뒤 다시 요청해, 오래된 스냅샷이 최신 로컬 델타를 덮지 않게 합니다.

# 보드 즐겨찾기 API

`GET`은 현재 사용자의 즐겨찾기 상태를 반환합니다. `PUT`은 현재 사용자가 읽을 수 있고 필요한 비밀번호 확인까지 마친 보드를 `BoardFavorite`에 추가하고, `DELETE`는 현재 사용자의 관계만 멱등적으로 제거합니다. 보드 더보기와 홈 카드가 이 세 API를 함께 사용하므로 문구와 상태가 일치합니다.

즐겨찾기는 알림 구독인 `BoardFollow`와 독립적이므로 팔로우를 해제해도 유지됩니다. 홈 Server Component는 다시 접근 가능한 보드 ID에 대해서만 이 상태를 내려줍니다.

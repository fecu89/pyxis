# app/api/public/sessions 개요

- `join/route.ts`: 공개 PIN과 닉네임을 검증하고 공개 참여자를 생성한다. 난수 키 원문은 HttpOnly 쿠키, SHA-256 해시만 DB에 저장한다. 같은 학교 IP를 공유하는 한 반이 함께 들어올 수 있도록 기본 참여 상한은 120회/분이고, 존재하지 않거나 로그인 전용인 PIN은 별도 20회/분 상한으로 전수 대입을 막는다.
- `[sessionId]/`: 공개 세션 상태, ASYNC 진행·답안 제출, 본인 리포트를 세션별 게스트 키로 제공한다.

공개 JSON 요청은 모두 실제 스트림 기준 본문 상한을 사용합니다. 참여 이후 상태·답안 제한은 IP가 아니라 `participantId`를 함께 키로 써 같은 NAT의 다른 학생과 충돌하지 않습니다.

# 개인 대시보드 폴더 API

`/api/dashboard`는 현재 로그인 사용자의 폴더만 생성·이름 변경·삭제하고 보드 포함 여부를 갱신합니다.

- 폴더 이름은 NFKC·공백 정리·소문자 `nameKey`로 같은 이름 중복을 막습니다.
- 모든 변경 요청은 same-origin과 활성 세션을 검사하고, 폴더 ID에는 반드시 현재 사용자 조건을 함께 둡니다.
- 보드 추가 시 현재 읽기 권한과 비밀번호 확인을 다시 검사합니다.
- 하나의 보드는 여러 폴더에 포함할 수 있고, 폴더 삭제는 연결 행만 정리하며 보드에는 영향을 주지 않습니다.

# Overview

이 폴더는 pyxis 구현에서 `app/(marketing)` 영역을 담당합니다. 셸이 없는 공개 화면이라 각
페이지가 자체 헤더를 갖습니다.

- `page.tsx`: 공개 랜딩(`/`). 이미 로그인한 사용자가 오면 `callbackUrl`이나 대시보드로 넘깁니다
  — 이 화면은 로그인 여부를 모르고 항상 "로그인" 버튼을 보여 줘서, 그냥 두면 세션이 끊긴 것처럼
  보였습니다. `?login=1`이 붙으면 로그인 모달을 열어 둔 채 렌더링합니다. 카피는 패드·퀴즈·설문
  활동을 모아 AI가 생기부 문안 초안까지 정리하는 플랫폼으로 설명합니다(자세한 배경은
  `components/landing/overview.md` 참고).
- `guide/page.tsx`: 활용법(`/guide`). 패드 → 참여 → 피드백 → 퀴즈 → 리포트 → 관리 여섯 단계로
  수업에서의 사용 흐름을 설명합니다. 사이트맵에 들어가는 두 공개 주소 중 하나입니다. 아직 설문·AI
  생기부는 이 여섯 단계에 들어가 있지 않습니다 — 홈(`page.tsx`)만 먼저 갱신했고, `/guide`를 같이
  넓힐지는 별도로 정할 일입니다.

# app/(play)/go 개요

`/go/[slug]`는 사람이 입력한 짧은 별칭을 원래 참여 주소로 돌려보내는 공개 리다이렉트 경로입니다.

- 패드는 `/b/{boardSlug}`, 진행 중인 퀴즈 세션은 `/j/{pinCode}`, 설문은 `/s/{formSlug}`로 이동합니다.
- 별칭 형식을 검증하고 대상의 삭제 상태와 퀴즈 세션 마감·취소 상태를 확인합니다. 유효한 대상이 없으면 404입니다.
- 이 페이지는 로그인이나 콘텐츠 권한을 승인하지 않습니다. 리다이렉트된 각 대상 페이지가 기존 접근 정책을 다시 검사합니다.
- 조회 결과가 바뀔 수 있으므로 `dynamic = "force-dynamic"`으로 동작합니다.

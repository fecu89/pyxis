# 패드 라우트 개요

이 폴더는 pyxis의 패드 열람 경로를 담당합니다.

- `/b/{slug}`: 패드 본문
- `/b/{slug}/posts/{postId}`: 게시물 독립 상세 페이지
- `/b/{slug}/present`: 발표 화면
- `/b/{slug}/print`: 인쇄 화면
- `/b/{slug}/opengraph-image`: 공개 가능한 패드의 동적 공유 썸네일

게시물 카드는 더 이상 화면 위에 상세 모달을 띄우지 않고 독립 URL로 이동합니다. 상세 경로도 패드
본문과 같은 공개 범위·비밀번호·멤버십 판정을 사용하며, 권한이 확인된 뒤 해당 게시물 한 건만
조회합니다. 링크 또는 전체 공개 게시물은 제목과 본문 요약을 메타데이터에 제공하고 패드 OG 이미지를
재사용합니다. 보호된 패드는 게시물 정보를 노출하지 않고 pyxis 기본 메타데이터와 썸네일을 반환합니다.

세부 접근 정책은 `[slug]/overview.md`, 게시물 화면은 `[slug]/posts/[postId]/overview.md`,
메타데이터 렌더러는 `utils/seo/overview.md`를 참고합니다.

# 보드 페이지 개요

이 폴더는 보드 공개 범위와 현재 사용자의 DB 멤버십을 기준으로 보드 화면을 제공합니다.

- 보드 URL은 `/b/{slug}` 구조를 유지하며, 전체 slug를 보드의 고유 조회 키로 사용합니다.
- slug의 한글은 제거하거나 DB에 percent-encoding하지 않습니다. `lib/board/route-paths.ts`가 DB의
  순수 slug와 라우터의 percent-encoded slug를 모두 받아 URL에서는 정확히 한 번만 인코딩합니다.
  과거 게시물 카드가 만든 `%25EC...` 이중 인코딩 주소는 최대 2회 디코딩해 같은 패드로 복구합니다.
- username 경로나 별도 short ID 분리는 도입하지 않으며, 생성된 주소는 보드 제목 변경과 무관하게 유지합니다.
- `링크 공개(LINK)` 보드는 URL을 아는 사람이 로그인 없이 열고 공유할 수 있으며, 비멤버에게는 글쓰기·댓글·반응·수정 UI와 API 권한을 주지 않습니다. 비밀번호가 설정된 경우에는 로그인 대신 보드 비밀번호만 추가로 확인합니다.
- `전체 공개(PUBLIC)` 보드는 관리자가 정한 방문자 권한과 로그인 요구 설정에 따라 열립니다.
- 비공개 보드 등 로그인이 필요한 보드에 익명으로 접근하면 홈의 Kakao 로그인 모달로 이동하고, 로그인 후 원래 보드로 돌아옵니다.
- 로그인했지만 멤버가 아니면 보드명·관리자 안내와 `권한 요청하기` 화면을 표시합니다.
- 페이지 가드는 사용자 경험을 담당하고, 최종 데이터 권한은 `lib/board/queries.ts`와 각 Route Handler에서 다시 검사합니다.
- 게시물 카드는 `/b/{slug}/posts/{postId}` 독립 상세 경로로 이동합니다. 이 경로도 같은 보드 접근 판정을 재사용하고 해당 게시물 한 건만 조회합니다.
- `generateMetadata`와 `[slug]/opengraph-image.tsx`는 `utils/seo/boardMetadata.ts`의 같은 공개 판정을
  사용합니다. 비밀번호 없는 LINK는 제목·설명·보드 색상 기반 1200×630 공유 카드를 제공하지만
  `noindex`이며, 익명 읽기 PUBLIC만 검색 색인을 허용합니다. PRIVATE·로그인 필요·NO_ACCESS·비밀번호
  보호 패드는 제목과 설명을 메타태그에 싣지 않고 pyxis 기본 썸네일을 반환합니다. 발표·인쇄 경로는
  공개 가능한 제목은 유지하되 중복 색인을 피하려고 항상 `noindex`입니다.
- 게시물 상세 메타데이터도 같은 공개 판정을 사용합니다. 공개 가능한 `PUBLISHED` 게시물만 게시물
  제목과 본문 요약을 내보내며, 보호된 패드·승인 대기·거절·삭제 게시물은 내용을 노출하지 않습니다.
